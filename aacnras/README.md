# AACNRAS web app

The Next.js app for the Accessibility-Aware Campus Navigation and Route Advisory System.

**Full documentation is in the [main README](../README.md):** features, how routing works, data sources, the survey checklist, API reference and deployment notes.

```bash
npm install
npm run dev          # http://localhost:3000
npm test             # unit tests
npm run import:osm   # refresh paths, places and elevations from OpenStreetMap
```
